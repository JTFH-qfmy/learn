# PGC 仿真

记录 LabVIEW 中的 PGC 信号生成、解调流程与参数对照实验。

每项实验创建独立子目录，使用[可复现记录](../templates/reproducible-record.md)和[实验参数](../templates/experiment-parameters.md)模板。保存入口 VI、子 VI、项目文件与必要依赖；在记录中写清 LabVIEW 版本、位数、工具包、打开入口和运行顺序，并附关键框图或前面板截图。

参数至少说明采样率、采样点数或时长、载波频率、调制深度、待测相位信号、滤波设置和噪声设置。随机噪声需记录种子或保留输入序列。给出评价指标、计算方法和参考信号。

可从“无噪声基线 → 单参数变化 → 噪声影响”逐步开展；以上是建议顺序，尚无已完成实验。
